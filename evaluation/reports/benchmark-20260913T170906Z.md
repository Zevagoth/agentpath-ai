# AgentPath AI - retrieval benchmark

> All knowledge-base content is **fictional and synthetic**.

## Method

- Query set: **30 queries** - 26 supported (a procedure answers them) and 4 unsupported (nothing in the knowledge base answers them).
- Retrieval quality (Recall@1, Recall@3, MRR) is measured on **supported queries only**.
- Abstention accuracy is measured on **unsupported queries only**.
- False abstention rate is the share of *supported* queries the system refused to answer, reported alongside recall so a cautious threshold cannot flatter the result.
- Latency: 3 measured runs per query, after 1 discarded warm-up run per query. Percentiles are nearest-rank, not interpolated.
- Top-k: 3.
- Reranking: **disabled**.

## Modes compared

- **`lexical_baseline`** - Keyword overlap over the procedure corpus. No embeddings, no synonyms, no typo correction. Benchmark reference only.
- **`ragflow_hybrid`** - RAGFlow hybrid retrieval (BM25 + vector) on the raw query, without AgentPath query understanding.
- **`agentpath_full`** - The full AgentPath path over HTTP: understanding, hybrid retrieval, grading.
